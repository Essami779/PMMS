لوحة تحكم احترافية وعصرية مبنية على **Laravel 12** و **TailwindCSS** و **Alpine.js** و **Chart.js**، مصممة لتكون قالب أساسي (Starter Kit) قابل لإعادة الاستخدام في بناء وتطوير أي مشاريع وأنظمة جديدة بسرعة وسهولة، مع الحفاظ على أعلى معايير الجمالية وتجربة المستخدم (UI/UX).

---

## ✨ المميزات الرئيسية للنظام

### 1. الرؤية البصرية والتصميم (Design & Aesthetics)
- **الوضع المزدوج (Dark / Light Mode)**: تبديل سلس وتلقائي بين الوضعين النهاري والليلي مع حفظ الخيار في المتصفح.
- **الساعة التناظرية والرقمية الحية (3D Live Clock)**: تدعم التوقيت المباشر والتقويم المزدوج (هجري وميلادي).
- **الخطوط العربية الراقية**: تكامل كامل لخطوط Google Fonts (Cairo, Readex Pro, Alyamama, Tajawal).
- **تصميم الزجاج والمؤثرات (Glassmorphism 2.0)** والتدرجات اللونية المتناسقة.

### 2. مركز إعدادات النظام (System Settings Hub)
- **إدارة المستخدمين والحسابات (`/users`)**: إنشاء وتعديل الحسابات، وتعيين الأدوار والصلاحيات المباشرة.
- **مركز الأدوار ومصفوفة الصلاحيات (`/roles`)**: إدارة مصفوفة الصلاحيات الحية والشاملة مبنية على حزمة `spatie/laravel-permission`.
- **إدارة القوائم المساعدة والترميز والعملات (`/lookups`)**:
  - الأقسام والوحدات الإدارية (Units & Departments) مع الأكواد والألوان.
  - المحافظات والمناطق الجغرافية (Governorates & Locations).
  - العملات وأسعار الصرف (Multi-Currency Engine) مع الأعلام والرموز وحالة التفعيل.
- **سجل التدقيق والأمان والنشاطات (`/audit`)**: تتبع وتوثيق دقيق لكافة العمليات المنفذة في المنظومة عبر `spatie/laravel-activitylog`.
- **نظام النسخ الاحتياطي الذكي (`/backups`)**: إنشاء نسخ لقاعدة البيانات والمشروع (SQL / ZIP) وتنزيلها واستعادتها ورفعها مع الحماية من Path Traversal.
- **سلة المهملات والمحذوفات الشاملة (`/trash`)**: استعادة السجلات المحذوفة مؤقتاً أو حذفها نهائياً.
- **البحث الشامل الفوري والتنقل السريع (`/global-search`)**: نافذة بحث منبثقة وسريعة للتنقل بين الصفحات والبيانات.

### 3. لوحة التحكم والإحصائيات (`/dashboard`)
- بطاقات المؤشرات الأساسية والمقاييس اللحظية.
- مخططات بيانية تفاعلية (Chart.js) لمعدل النشاط وتوزيع الأدوار.
- سجل العمليات والنشاطات المباشرة.
- لوحة مراقبة بيئة التشغيل وصحة الخادم (PHP, Laravel, Database, Timezone).

## 🚀 متطلبات التشغيل والتثبيت

1. **المتطلبات الأساسية**:
   - PHP >= 8.2
   - MySQL / MariaDB
   - Composer
   - Node.js & NPM

2. **خطوات التشغيل**:
   ```bash
   # تثبيت حزم PHP
   composer install

   # تثبيت حزم JavaScript
   npm install

   # بناء وتجهيز الواجهات
   npm run build

   # تهيئة قاعدة البيانات والبيانات الأولية
   php artisan migrate:fresh --seed

   # تشغيل خادم التطوير
   php artisan serve
