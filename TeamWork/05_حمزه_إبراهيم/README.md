## 🎯 1. ملخص المسؤوليات ونطاق العمل في أسبوع العمل الكامل (Sprint 7 Days)

يعمل حمزه إبراهيم بالشراكة المباشرة مع **عبدالحميد الريشاني** لبناء وإطلاق الواجهات العامة لموقع نظام PMMS وبوابات الزوار والشركاء:

### أ. بناء الأدلة العامة وفهارس المنظومة (Public Directories & Listings)
- [ ] **دليل الفرق والمشاريع العامة (`teams/index.blade.php`):**
  - بناء بطاقات استعراض الفرق التقنية المشاركة، مجالات اختصاصها، ونسبة إنجازها في مشاريع التخرج.
  - إضافة شريط فلترة للفرق حسب المسار (تقني، أبحاث، حلول أعمال).
- [ ] **دليل الشركات والمؤسسات الراعية (`companies/index.blade.php`):**
  - عرض الشركات الشريكة، مجالات التعاون، والمشاريع المعروضة للتبني أو الرعاية.
- [ ] **دليل المستشارين والخبراء الأكاديميين (`consultants/index.blade.php`):**
  - بناء بطاقات الخبراء، التخصص الدقيق، أزرار طلب الاستشارة، والتقييمات.

### ب. بوابات المسارات التعريفية والتقديم (Track Overviews & Features)
- [ ] تطوير صفحة مسار الشركات والمؤسسات (`tracks/companies.blade.php`) الموضحة لآلية طرح التحديات والمشاريع.
- [ ] تطوير صفحة مسار المستشارين والخبراء (`tracks/consultants.blade.php`) الموضحة لآلية توجيه وإرشاد الفرق.
- [ ] بناء قسم آلية العمل (How It Works) والأسئلة الشائعة (FAQ Accordion) في الواجهة الرئيسية.

### ج. النماذج التفاعلية والبحث الحي (Interactive Modals, Forms & Search)
- [ ] بناء وتنسيق النوافذ المنبثقة التفاعلية (Modals) للتقديم والانضمام السريع.
- [ ] بناء واجهة البحث الشامل بالواجهة العامة (`search/index.blade.php`) وتفعيل البحث والفلترة الفورية باستخدام **Alpine.js**.
- [ ] التحقق الفوري من مدخلات النماذج (Client-Side Validation) لضمان تجربة مستخدم سلسة ودقيقة.

## 📅 2. جدول المهام اليومية للأسبوع (Day-by-Day Schedule)

| اليوم | المهام التنفيذية لحمزه إبراهيم | الشريك والتكامل |
| :---: | :--- | :--- |
| **اليوم 1** | بناء وتجهيز مكتبة المكونات التفاعلية للواجهة العامة (`components/frontend/`). | التنسيق مع عبدالحميد لتوحيد ألوان وخطوط الموقع. |
| **اليوم 2** | بناء قسم مميزات المنصة (Features Grid) وقسم آلية العمل في صفحة الهبوط. | التكامل مع عبدالحميد داخل `welcome.blade.php`. |
| **اليوم 3** | تصميم وتطوير صفحتي مسار الشركات (`tracks/companies`) ومسار المستشارين (`tracks/consultants`). | توحيد هيكل المسارات مع صفحة مسار الفرق. |
| **اليوم 4** | بناء صفحات الأدلة العامة للشركات (`companies/`) والمستشارين (`consultants/`) مع الفلاتر. | التنسيق مع عبدالحميد لتطوير صفحة دليل الفرق بالتوازي. |
| **اليوم 5** | بناء نماذج التقديم المنبثقة، وتطوير شاشة البحث التفاعلي (`search/index.blade.php`). | ربط النماذج مع `FrontendController`. |
| **اليوم 6** | فحص التجاوب وسرعة استجابة الفلاتر والنماذج على شاشات الهواتف والأجهزة اللوحية. | فحص ومراجعة تجربة الاستخدام المشتركة مع عبدالحميد. |
| **اليوم 7** | التدقيق النهائي للمحتوى التفاعلي، خلو الواجهات من الأخطاء البرمجية، وتجهيز العرض. | جلسة تسليم واعتماد مشتركة مع عصام الخطيب. |

## 🔗 3. المدخلات والمخرجات والتكامل البرمجي

- **المدخلات التي يستند إليها حمزه:**
  - القالب العام وتصميم صفحات الهبوط من زميله **عبدالحميد الريشاني**.
  - مسارات وبيانات الـ `FrontendController` من مسار الباك إند.
- **المخرجات التي يسلمها حمزه:**
  - صفحات أدلة عامة مفهرسة وجذابة بصرياً.
  - نماذج تفاعلية وبحث حي يربط الزوار بمسارات المنصة بسهولة.
