# 📐 خطة العمل التنفيذية — حسين الحيدري

**العضو:** حسين الحيدري  
**الدور الأساسي:** محلل النظم والمخططات + مسؤول هندسة المتطلبات وحالات الاستخدام بكتاب التخرج  
**المشروع:** نظام إدارة ومتابعة المشاريع (PMMS) — جامعة الوطنية  
**المجلد:** `TeamWork/02_حسين_الحيدري/`

---

## 🎯 1. ملخص المسؤوليات ونطاق العمل في المرحلة الحالية (Sprint 1)

### أ. مهام كتاب ومشروع التخرج الأكاديمي

- [ ] صياغة **مبحث المشكلة والأهداف ونطاق النظام (Project Scope & Problem Statement)** وتضمينه في الفصل الأول والثالث.
- [ ] إعداد **مصفوفة المتطلبات الوظيفية (Functional Requirements - FR)** لنظام PMMS موزعة بدقة على البوابات:
  - بوابة العميل (Client Portal).
  - بوابة الموظفين والمشرفين (Employees & Supervisors).
  - لوحة التحكم المركزية والإدارة (Central Admin).
- [ ] إعداد **مصفوفة المتطلبات غير الوظيفية (Non-Functional Requirements - NFR)** وفق معايير الجودة (الأمان، الموثوقية، الأداء، قابلية الاستخدام) وترميزها أكاديمياً (NFR-01, NFR-02...).
- [ ] كتابة **جداول مواصفات حالات الاستخدام التفصيلية (Use Case Specifications)** متضمنة (اسم الحالة، الفاعل، الهدف، الشروط المسبقة، المسار الرئيسي، المسارات البديلة، شروط الانتهاء).

### ب. المخططات الهندسية المطلوبة (Diagrams)

- [ ] رسم **مخطط حالات الاستخدام العام (General Use Case Diagram)** لنظام PMMS.
- [ ] رسم مخططات حالات استخدام فرعية لكل بوابة رئيسية (Sub-system Use Cases).
- [ ] رسم **مخططات النشاط (Activity Diagrams)** للعمليات المحورية:
  1. دورة حياة إنشاء واعتماد مشروع جديد (Project Initiation & Approval).
  2. دورة إسناد المهمة للمطور ورفع الإنجاز واعتماده (Task Assignment & Review).
  3. دورة طلب سلفة مالية أو مستحقات مرحلية (Financial Milestone Request).

## 🔗 2. المدخلات والمخرجات والتكامل

- **المدخلات التي يستند إليها حسين:**
  - وثيقة دليل المنصة الشامل الموجودة في `01_Documentation_Reports/Architecture_Guide/دليل_المنصة_الشامل_PMMS.md`.
  - مخرجات النقاش مع قائد المشروع (عصام الخطيب).
- **المخرجات التي يسلمها حسين:**
  - جداول المتطلبات وحالات الاستخدام إلى **محمد المغربي** لبناء شاشات الـ UI على أساسها.
  - سيناريوهات استخدام النظام إلى **محمد الرقاص** لتحديد الصلاحيات ونقاط الـ API.
  - فصول التحليل والمخططات إلى زميله **عبدالحميد الريشاني** لتجميعها في كتاب التخرج وإلى **عصام الخطيب** للاعتماد.
