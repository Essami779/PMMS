## 🎯 1. ملخص المسؤوليات ونطاق العمل في أسبوع العمل الكامل (Sprint 7 Days)

يعمل حسين الحيدري جنباً إلى جنب مع **محمد الرقاص** لبناء وتطوير كافة واجهات لوحة التحكم الإدارية لنظام PMMS:

### أ. هيكلة وبناء قوالب لوحة التحكم (Admin Master Layouts & Components)
- [ ] تطوير القالب العام للوحة التحكم (`resources/views/layouts/app.blade.php`).
- [ ] بناء القائمة الجانبية التفاعلية (Sidebar) مع دعم طي/فتح القائمة، وتسليط الضوء على الرابط النشط.
- [ ] بناء شريط التنقل العلوي (Navbar/Header) مع زر التبديل بين الوضع الليلي والنهاري (Dark/Light Mode)، ومحدد الملف الشخصي، وقائمة الإشعارات.
- [ ] تجهيز مكتبة المكونات الإدارية المساعدة (`views/components/`):
  - بطاقات مؤشرات الأداء الحيوية (Metric KPI Cards).
  - جداول عرض البيانات المتقدمة مع الترقيم وأزرار الإجراءات (Data Tables).
  - النوافذ المنبثقة التفاعلية (Modals & Confirmation Dialogs) بـ Alpine.js.
  - حقول الإدخال والقوائم المنسدلة وأزرار الحالة وحقول الفلترة.

### ب. شاشات لوحة القيادة والمستخدمين والصلاحيات
- [ ] **لوحة القيادة الرئيسية (`dashboard.blade.php`):**
  - بطاقات الإحصائيات الحية (عدد المشاريع، الفرق النشطة، نسبة الإنجاز، المهام الحرجة).
  - حاويات الرسوم البيانية لتوزيع المهام وساعات العمل ومسارات المشاريع.
  - جدول آخر النشاطات والإشعارات الفورية.
- [ ] **إدارة المستخدمين (`users/index.blade.php`):**
  - جدول المستخدمين التفاعلي مع شريط الفلترة حسب الدور والحالة، ونموذج إضافة/تعديل مستخدم منبثق.
- [ ] **إدارة الأدوار ومصفوفة الصلاحيات (`roles/index.blade.php`):**
  - واجهة بصرية لمصفوفة الصلاحيات (Spatie Permissions Matrix) تتيح تفعيل وإلغاء الصلاحيات بسهولة.

### ج. مساحات عمل الفرق والرقابة والأنظمة المساندة
- [ ] **مساحة عمل الفريق التفاعلية (`team/workspace.blade.php`):**
  - تصميم وبناء لوحة مهام كانبان (Kanban Board Columns: Pending, In Progress, In Review, Done).
  - قائمة أعضاء الفريق وإحصائيات إنجازهم اليومية.
  - واجهات غرف النقاشات (`team/discussions.blade.php`) والاستشارات (`team/consultations.blade.php`).
- [ ] **شاشات المراقبة والتحكم الشاملة:**
  - واجهة سجل التدقيق والأمان (`audit/index.blade.php`).
  - واجهة النسخ الاحتياطي واستعادة البيانات (`backups/index.blade.php`).
  - واجهة سلة المهملات والمحذوفات (`trash/index.blade.php`).
  - واجهة القوائم المساعدة والترميز (`lookups/index.blade.php`).

## 📅 2. جدول المهام اليومية للأسبوع (Day-by-Day Schedule)

| اليوم | المهام التنفيذية لحسين الحيدري | الشريك والتكامل |
| :---: | :--- | :--- |
| **اليوم 1** | بناء وتوحيد `layouts/app.blade.php`، القائمة الجانبية (Sidebar)، والشريط العلوي (Navbar). | التنسيق مع محمد الرقاص لضبط الروابط والـ Asset Bundling. |
| **اليوم 2** | بناء شاشة `dashboard.blade.php`، وبطاقات الـ KPIs ورسوم توزيع المشاريع بـ Tailwind و Alpine. | استلام متغيرات الإحصائيات من `DashboardController`. |
| **اليوم 3** | تصميم واجهات المستخدمين (`users/`) وواجهة مصفوفة الصلاحيات والأدوار (`roles/`). | استلام بيانات الـ Roles والـ Permissions وتأمين النماذج. |
| **اليوم 4** | بناء لوحة مساحة العمل (`team/workspace.blade.php`) ولوحة مهام كانبان التفاعلية. | ربط أزرار النقل وتغيير حالة المهمة مع `TeamTaskController`. |
| **اليوم 5** | بناء واجهات النقاشات، الاستشارات، وسجل التدقيق (`audit/`) والنسخ الاحتياطي (`backups/`). | ربط أحداث الإرسال مع `AuditLogController` و `BackupController`. |
| **اليوم 6** | فحص التجاوب التام لشاشات لوحة التحكم على الموبايل والتابلت (Responsive UI Audit). | مراجعة تكامل النماذج والحماية مع محمد الرقاص. |
| **اليوم 7** | الاختبار الوظيفي النهائي لشاشات الداشبورد، إزالة أي ثغرات بصرية، وتجهيز العرض الحي. | الاعتماد والمراجعة مع قائد المشروع عصام الخطيب. |

## 🔗 3. المدخلات والمخرجات والتكامل البرمجي

- **المدخلات التي يستند إليها حسين:**
  - دوال ومسارات الـ Controllers والـ Form Requests الجاهزة من زميله **محمد الرقاص**.
  - إرشادات المعمارية والاعتماد من قائد المشروع **عصام الخطيب**.
- **المخرجات التي يسلمها حسين:**
  - شاشات لوحة تحكم كاملة ومتجاوبة مبنية بـ Blade متصلة بالباك إند.
  - تجربة مستخدم إدارية سلسة تدعم التفاعل السريع والوضع الليلي والنهاري.
