## 📄 البرومت الأول: توليد لوحة التحكم الرئيسية والمؤشرات (Dashboard KPI Cards & Layout)

> **طريقة الاستخدام:** انسخ النص التالي كاملاً وضعه في ChatGPT أو Claude أو Gemini لتوليد كود Blade متقدم للداشبورد:

```text
أنت مهندس واجهات أمامية وخبير في Laravel Blade و TailwindCSS و Alpine.js.
المشروع هو: "لوحة تحكم نظام إدارة ومتابعة المشاريع (PMMS Admin Dashboard)".
المطلوب منك كتابة كود Blade احترافي لواجهة لوحة القيادة (dashboard.blade.php):

المواصفات المطلوبة:
1. بطاقات المؤشرات الحيوية (KPI Metric Cards) بألوان وتأثيرات عصرية (Glassmorphism / Gradient Accents):
   - إجمالي المشاريع النشطة (Active Projects) مع نسبة النمو.
   - إجمالي الفرق والمطورين المسجلين (Teams Count).
   - نسبة إنجاز المهام الإجمالية (Tasks Completion Rate).
   - ساعات العمل والإنتاجية المسجلة هذا الأسبوع.
2. قسم شبكة الرسوم البيانية والأداء:
   - حاوية Chart.js لمتابعة وتيرة إنجاز المشاريع.
   - شريط دائري أو عمودي لتوزيع المهام حسب الحالات (Pending, In Progress, In Review, Done).
3. جدول النشاطات الفورية (Live Activity Feed):
   - عرض آخر المهام المحدثة وأسماء المطورين مع الشارات (Badges) الملونة للحالات.
4. دعم كامل للاتجاه من اليمين لليسار (RTL) مع تناسق كامل للوضع الليلي والنهاري (Dark/Light Mode).
5. كود نظيف مقسم باستخدام Blade Components وفئات TailwindCSS الحديثة دون أي ملفات CSS خارجية غير ضرورية.
```

## 📊 البرومت الثاني: توليد لوحة كانبان التفاعلية لإدارة المهام (Kanban Board UI)

> **طريقة الاستخدام:** انسخ النص التالي لتوليد شاشة كانبان تفاعلية لمساحة عمل الفرق:

```text
أنت خبير واجهات مستخدم متقدم في Laravel و TailwindCSS و Alpine.js.
المطلوب بناء واجهة لوحة كانبان تفاعلية لإدارة مهام المشاريع (Kanban Board Component) داخل مساحة عمل الفريق (workspace.blade.php):

المتطلبات الدقيقة:
1. تقسيم الأعمدة إلى 4 مراحل رئيسية:
   - المهام قيد الانتظار (Pending Tasks)
   - المهام الجاري تنفيذها (In Progress)
   - المهام قيد المراجعة والتدقيق (In Review)
   - المهام المكتملة والمعتمدة (Done / Completed)
2. بطاقة المهمة (Task Card):
   - اسم المهمة والوصف المختصر.
   - وسم الأولوية (High/Medium/Low) بلون مميز.
   - اسم وصورة المطور المسؤول (Assignee Avatar).
   - تاريخ التسليم وعداد الأيام المتبقية.
3. التفاعل بـ Alpine.js:
   - إمكانية نقل البطاقة بين الأعمدة أو تغيير حالتها عبر زر تفاعلي سريع يرسل طلب AJAX إلى مسار Laravel (PATCH /my-team/{team}/tasks/{task}/status).
4. نافذة منبثقة (Alpine Modal) لإضافة مهمة جديدة تتضمن حقول التحقق والتاريخ وتحديد الأولوية.
5. تصميم متجاوب يعمل بسلاسة على الشاشات الكبيرة والهواتف الذكية.
```
