## 🔄 البرومت الأول: توليد مخططات Sequence و Class و State Diagrams (كود Mermaid والشرح)

> **طريقة الاستخدام:** انسخ النص التالي كاملاً وضعه في أداة الذكاء الاصطناعي:

```text
أنت مهندس معماري أول للبرمجيات وخبير نمذجة النظم الموزعة (Senior Software Architect & UML Expert).
المشروع هو: "نظام إدارة ومتابعة المشاريع (PMMS - Project Management & Monitoring System)".
البيئة التقنية: تطبيق Flutter يعمل Offline-First، باك إند Laravel 12 API، قاعدة بيانات PostgreSQL ومخزن محلي Hive.

المطلوب منك:
1. توليد كود Mermaid لمخطط تتابع تفصيلي (Sequence Diagram) يوضح دورة مزامنة البيانات دون اتصال (Offline Sync):
   - المستخدم يضيف مهمة جديدة أثناء انقطاع الإنترنت -> حفظ محلي في Hive -> إرجاع نجاح فوري للواجهة مع علامة Pending Sync.
   - عودة اتصال الإنترنت -> طبقة مزامنة Sync Manager في Flutter ترسل حزمة التغييرات (Batch Sync Request) إلى Laravel API.
   - الباك إند يتحقق من الصلاحيات ويحفظ في PostgreSQL ويرجع تأكيد واستجابة بالمعرفات الجديدة -> تحديث المخزن المحلي وإزالة علامة الانتظار.
2. توليد كود Mermaid لمخطط الفئات (Class Diagram) يوضح العلاقات والخصائص والدوال للفئات التالية:
   - User, Role, Project, Milestone, Task, SyncTransaction.
3. توليد كود Mermaid لمخطط الآلة ذات الحالات (State Machine Diagram) لحالة المشروع وحالة المهمة مع توضيح الشروط (Guards) والمسببات (Triggers) للانتقال بين حالة وأخرى.
4. كتابة شرح تحليلي معماري لكل مخطط مناسب للإدراج المباشر في الفصل الثالث من كتاب التخرج الأكاديمي.
```

## 📖 البرومت الثاني: تجميع وتنسيق وضبط جودة فصول كتاب التخرج الأكاديمي (Thesis Compilation)

> **طريقة الاستخدام:** انسخ النص التالي والصق مسودات فصول زملائك أسفله لمواءمتها وتنسيقها:

```text
أنت محرر أكاديمي وخبير إخراج رسائل ومشاريع التخرج الجامعية لقسم نظم المعلومات الإدارية (MIS Academic Editor).
لدي مسودات الفصول الثلاثة الأولى لمشروع تخرجنا (نظام إدارة ومتابعة المشاريع PMMS):
- الفصل الأول: مقدمة المشروع، المشكلة، الأهداف، النطاق والأهمية.
- الفصل الثاني: الدراسات السابقة والمقارنة المعيارية ودراسة الجدوى الرباعية.
- الفصل الثالث: التحليل الهندسي الشامل للنظام (المتطلبات، Use Cases، DFD، ERD، Sequence، Class، ومعمارية النظام).

المطلوب منك:
1. مواءمة وتوحيد الصياغة اللغوية والأكاديمية للمحتوى المرفق لتكون بنمط موحد ومحترف.
2. ضبط تسلسل الأفكار والروابط الانتقالية بين المباحث والفصول لمنع أي انقطاع أو تكرار.
3. تجهيز فهرس المحتويات الأكاديمي المفصل (Table of Contents) وفهرس الجداول وفهرس الأشكال والمخططات وفق المعايير المعتمدة في جامعة الوطنية.
4. التأكد من دقة الإحالات المرجعية والمصطلحات التقنية الإنجليزية المقابلة للمصطلحات العربية.

[انسخ والصق هنا مسودات الفصول المجمعة من زملائك لمواءمتها وتنسيقها]
```
