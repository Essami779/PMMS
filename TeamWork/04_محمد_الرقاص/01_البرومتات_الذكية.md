## ⚡ البرومت الأول: توليد معمارية Laravel 12 API نظيفة ومؤمنة (Clean Controller & Resources)

> **طريقة الاستخدام:** انسخ النص التالي كاملاً وضعه في ChatGPT أو Claude أو Gemini:

```text
أنت مهندس باك إند أول وخبير في إطار عمل Laravel 12 و PHP 8.2+ وتصميم واجهات RESTful API (Senior Laravel Architect).
نحن نبني الواجهة الخلفية لمنصة: "نظام إدارة ومتابعة المشاريع (PMMS - Project Management & Monitoring System)".

المطلوب منك:
1. بناء وتوليد كود متكامل لوحدة المصادقة وإدارة المشاريع (Authentication & Projects API) وفق أفضل الممارسات:
   - AuthController: تسجيل الدخول عبر Laravel Sanctum، التحقق من كلمة المرور، توليد Personal Access Token مع الصلاحيات (Abilities)، وتسجيل الخروج.
   - LoginRequest: قواعد تحقق صارمة (Validation Rules) مع رسائل خطأ واضحة باللغة العربية.
   - ProjectController: دوال (index, store, show) مع تطبيق الـ Authorization Policies والترقيم والفرز.
   - ProjectResource & UserResource: كود تحويل المخرجات إلى بنية JSON موحدة ومرتبة تشمل (status, message, data, meta).
2. معالجة الأخطاء (Global Exception Handling) بحيث يتم إرجاع استجابات متسقة دائماً في حال الفشل (مثل 401 عند انتهاء الجلسة أو 422 عند فشل التحقق).
3. كتابة كود PHP نظيف وحديث (Typed properties, Match expressions, Strict types) بدون اختصارات جاهز للاستخدام المباشر.
```

## 📡 البرومت الثاني: توليد ملف توثيق الـ API ومجموعة Postman Collection بصيغة JSON

> **طريقة الاستخدام:** انسخ النص التالي وضعه في أداة الذكاء الاصطناعي:

```text
أنت مهندس واجهات برمجة وتكامل أنظمة (API Integration & QA Specialist).
أريد منك توليد هيكل ملف Postman Collection v2.1 بصيغة JSON لنقاط الاتصال الخاصة بنظام إدارة ومتابعة المشاريع PMMS.

المطلوب أن تشمل المجموعة النقاط التالية:
1. مجلد Auth:
   - Login: مع Body تجريبي لحساب المدير (email, password) وحفظ التوكن تلقائياً في متغير البيئة {{bearer_token}} عبر Tests script.
   - Profile: جلب بيانات الحساب الحالي باستخدام Bearer Token.
   - Logout: إلغاء الجلسة.
2. مجلد Projects:
   - List Projects: مع معلمات البحث والفلترة (?status=active&page=1).
   - Create Project: مع Body كامل (title, description, budget, start_date, end_date, priority).
   - Get Project Details: جلب بيانات مشروع محدد بالـ ID.
3. مجلد Lookups:
   - Get Departments: جلب قائمة الأقسام مع الألوان والأكواد.
قم بكتابة ملف الـ JSON بشكل صحيح تماماً بحيث يمكن استيراده مباشرة بنقرة واحدة داخل Postman.
```
