## 🎯 1. ملخص المسؤوليات ونطاق العمل في أسبوع العمل الكامل (Sprint 7 Days)

يقود محمد الرقاص بنية الباك إند ويعمل بتنسيق وثيق مع زميله **حسين الحيدري** لتمكين وتغذية لوحة التحكم الإدارية، وتوفير واجهات الـ API اللازمة لتطبيق الموبايل:

### أ. إدارة قاعدة البيانات والترحيل (Database Migrations & Models)
- [ ] مراجعة وتدقيق ملفات الترحيل (**Migrations**) لجداول النظام:
  - جداول الحسابات والملفات الشخصية (`users`, `user_profiles`).
  - جداول الفرق والمشاريع والمراحل والمهام (`teams`, `team_members`, `projects`, `milestones`, `tasks`).
  - جداول الصلاحيات والأدوار عبر حزمة `spatie/laravel-permission`.
  - جداول القوائم المساعدة والترميز (`lookups_units`, `governorates`, `currencies`).
  - جداول التدقيق والأنشطة (`audit_logs`) والنسخ الاحتياطي (`backups`).
- [ ] بناء نماذج **Eloquent Models** مع تعريف العلاقات الكاملة (`hasMany`, `belongsTo`, `belongsToMany`) ومحددات الوصول ونطاقات الاستعلام (Query Scopes).

### ب. منطق الأعمال ووحدات التحكم للوحة التحكم (Admin Controllers & Services)
- [ ] **إدارة المصادقة والأمان:**
  - إعداد وتأمين مسارات تسجيل الدخول والخروج مع الحماية من هجمات التخمين (Rate Limiting).
  - ضبط صلاحيات الوصول ومصفوفة الأدوار بالـ Middlewares.
- [ ] **وحدات تحكم لوحة الإدارة المركزية ومساحات العمل:**
  - `DashboardController`: استخراج إحصائيات الأداء والمشاريع والمهام الحية.
  - `UserController` & `RoleController`: إدارة المستخدمين وتعيين الأدوار ومزامنة الصلاحيات.
  - `TeamWorkspaceController` & `TeamTaskController`: منطق إدارة مساحات الفرق وتحديث حالات المهام.
  - `TeamDiscussionController` & `TeamConsultationController`: إدارة غرف النقاش والاستشارات.
  - `AuditLogController` & `BackupController` & `TrashController`: منطق التدقيق، والنسخ الاحتياطي، وإدارة سلة المحذوفات.

### ج. واجهات البرمجة الموثقة لتطبيق الموبايل (RESTful API & Sanctum)
- [ ] توفير وتأمين مسارات الـ API عبر **Laravel Sanctum** لخدمة تطبيق Flutter (قيادة الأخ عصام الخطيب).
- [ ] إنشاء **API Resources** و **Form Requests** لتوحيد تنسيق البيانات والتحقق من صحتها.
- [ ] توثيق نقاط الاتصال ومشاركة ملف الـ Postman المحدث مع قائد المشروع.

## 📅 2. جدول المهام اليومية للأسبوع (Day-by-Day Schedule)

| اليوم | المهام التنفيذية لمحمد الرقاص | الشريك والتكامل |
| :---: | :--- | :--- |
| **اليوم 1** | تدقيق الـ Migrations وهيكلية مجلدات الباك إند (Services / Requests). | تسليم هيكل البيانات لحسين الحيدري لبناء الـ Layouts. |
| **اليوم 2** | برمجة `DashboardController` بمنطق استعلامات سريع وتوفير إحصائيات حقيقية للداشبورد. | تغذية شاشة `dashboard.blade.php` بالبيانات والمتغيرات. |
| **اليوم 3** | برمجة منطق إدارة المستخدمين ومزامنة الصلاحيات بـ `spatie/laravel-permission`. | ربط أفعال الحفظ والتعديل مع واجهات حسين الحيدري. |
| **اليوم 4** | برمجة منطق مساحة العمل والمهام والوثائق (`TeamWorkspaceController`). | ربط لوحة الكانبان وأزرار الحالات في الواجهة. |
| **اليوم 5** | برمجة منطق غرف النقاش والاستشارات وسجل التدقيق والنسخ الاحتياطي والسلة. | ربط الواجهات الإدارية والتأكد من تسجيل النشاطات. |
| **اليوم 6** | تحسين أداء استعلامات قاعدة البيانات (Eager Loading)، معالجة مشكلة N+1، وتأمين الـ CSRF. | فحص سلاسة الاستجابة وسرعة التحميل مع حسين. |
