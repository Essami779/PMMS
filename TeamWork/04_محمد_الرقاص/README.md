## 🎯 1. ملخص المسؤوليات ونطاق العمل في المرحلة الحالية (Sprint 1)

### أ. تجهيز قاعدة البيانات وهيكلية Laravel 12 (Migrations & Models)
- [ ] مراجعة ملف الـ ERD وقاموس البيانات المسلم من **حمزه إبراهيم**.
- [ ] كتابة ملفات الترحيل (**Database Migrations**) في مشروع Laravel:
  - جدول المستخدمين `users` والملفات الشخصية `user_profiles`.
  - جداول الصلاحيات والأدوار عبر حزمة `spatie/laravel-permission` (`roles`, `permissions`, `model_has_roles`).
  - جداول القوائم المساعدة والترميز `lookups` (الأقسام، المحافظات، العملات).
  - جداول المشاريع `projects`، المراحل `milestones`، والمهام `tasks`.
- [ ] بناء نماذج **Eloquent Models** مع تعريف العلاقات (Relationships: `hasMany`, `belongsTo`, `belongsToMany`) ومحددات الوصول (Accessors/Mutators).

### ب. برمجة وتأمين واجهات الـ RESTful API
- [ ] إعداد وتأمين المصادقة عبر **Laravel Sanctum**:
  - `POST /api/v1/auth/login` (إصدار Bearer Token بناءً على صلاحيات الدور).
  - `POST /api/v1/auth/logout` (إلغاء التوكن الحالي بأمان).
  - `GET /api/v1/auth/me` (جلب بيانات المستخدم الحالي وصلاحياته وأدواره).
- [ ] بناء وحدات التحكم بالواجهات البرمجية (**API Controllers**) مع معايير نظيفة:
  - استخدام **Form Requests** للتحقق من صحة المدخلات (Validation).
  - استخدام **API Resources** لتوحيد وتنسيق مخرجات الـ JSON.
  - معالجة الأخطاء القياسية مع أكواد الاستجابة المناسبة (200, 201, 401, 403, 404, 422, 500).
- [ ] بناء نقاط اتصال المشاريع الأساسية:
  - `GET /api/v1/projects` (مع دعم الترقيم Pagination والفلترة حسب الحالة والقسم).
  - `POST /api/v1/projects` (إنشاء مشروع جديد مع تسجيل الفاعل في سجل النشاطات).
  - `GET /api/v1/projects/{id}` (عرض تفاصيل المشروع والمراحل التابعة له).

### ج. توثيق الـ API وتسليمه لتطبيق الموبايل
- [ ] تجهيز ملف توثيق الـ API ومجموعة **Postman Collection** مع متغيرات البيئة (Environment Variables) وتسليمها للأخ عصام الخطيب لتسريع عملية الربط مع Flutter.

## 🔗 2. المدخلات والمخرجات والتكامل

* **المدخلات التي يستند إليها محمد:**
  - مخطط الـ ERD وقاموس الحقول (Data Dictionary) من **حمزه إبراهيم**.
  - سيناريوهات وصلاحيات النظام من **حسين الحيدري**.
* **المخرجات التي يسلمها محمد:**
  - واجهات API حية وموثقة مع Postman Collection إلى **عصام الخطيب** لربطها بتطبيق الموبايل.
  - توثيق جداول قاعدة البيانات والـ API إلى **عبدالحميد الريشاني** لتضمينها في الفصل التقني بكتاب التخرج.
