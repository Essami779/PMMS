## 🚀 البرومت الأول: توليد معمارية تطبيق Flutter (Clean Architecture + Offline-First)

> **طريقة الاستخدام:** انسخ النص التالي كاملاً وضعه في ChatGPT أو Claude أو Gemini لتوليد كود وبنية التطبيق:

```text
أنت مهندس تطبيقات موبايل أول خبير في Flutter و Dart وتعمل على معمارية النظم للمشاريع الكبيرة (Senior Flutter Architect).
أنا أعمل كقائد ومطور لتطبيق الموبايل في مشروع تخرج أكاديمي لجامعة الوطنية بعنوان:
"نظام إدارة ومتابعة المشاريع (PMMS - Project Management & Monitoring System)".

المطلوب منك:
1. بناء وتوليد هيكلية معمارية نظيفة وشاملة (Flutter Clean Architecture) مقسمة على الطبقات التالية:
   - core/ (Network with Dio, Error Handling/Failures, Local Storage using Hive, Theme/Colors, Constants).
   - features/auth/ (Data: Datasources [Remote/Local], Models, Repositories; Domain: Entities, UseCases; Presentation: Controllers/Cubit/BLoC, Screens, Widgets).
   - features/projects/ (استعراض قائمة المشاريع وحالتها وإحصائياتها بنفس المعمارية النظيفة).
2. تطبيق نمط Offline-First بحرفية:
   - عند توفر الإنترنت، يتم جلب البيانات من الـ REST API وتخزينها محلياً في Hive.
   - عند غياب الإنترنت، يتم إرجاع البيانات المحفوظة محلياً بسلاسة دون انهيار التطبيق مع إشعار المستخدم بذلك.
3. كتابة كود Dart كامل، موثق، ونظيف بدون اختصارات أو نقاط حذف، مع تطبيق معايير الأمان (تخزين الـ Token بشكل مشفر عبر flutter_secure_storage).
4. تجهيز ثيم مزدوج أنيق (Light & Dark Mode) يدعم الخطوط العربية الرسمية (Cairo / Readex Pro) واستلهام مظهر Glassmorphism الحديث.
```

## 🔍 البرومت الثاني: مراجعة وتدقيق أعمال الفريق الأكاديمية والبرمجية (QA & Reviewer)

> **طريقة الاستخدام:** انسخ النص التالي والصق أسفله العمل المستلم من أي عضو بالفريق لفحصه وتدقيقه:

```text
أنت مراجع أكاديمي وبرمجي خبير (Lead Software Architect & Academic Thesis Reviewer) متخصص في مشاريع تخرج نظم المعلومات الإدارية (MIS) وهندسة البرمجيات.
أنا قائد فريق مشروع التخرج (نظام إدارة ومتابعة المشاريع PMMS).

المطلوب منك فحص وتقييم المحتوى المرفق (فصل أكاديمي / مخططات UML / كود برمجي / مواصفات API) وتقديم تقرير تدقيق احترافي يشمل:
1. مدى مطابقة المخرج للمعايير الأكاديمية المعمول بها في مشاريع التخرج بالجامعات وقسم MIS.
2. فحص الدقة الهندسية والمنطقية:
   - هل المخططات متناسقة وخالية من التناقض؟
   - هل توجد ثغرات أو سيناريوهات لم تتم معالجتها (Edge Cases & Failure Scenarios)؟
3. قائمة بالملاحظات الحرجة (Critical Issues) التي يجب تصحيحها فوراً قبل اعتماد المخرج.
4. مقترحات التحسين (Enhancement Suggestions) لرفع جودة العمل والحصول على تقدير ممتاز (A+).

[انسخ والصق هنا العمل المراد مراجعته من زميلك في الفريق]
```
