## 🎯 1. ملخص المسؤوليات ونطاق العمل في المرحلة الحالية (Sprint 1)

### أ. المهام القيادية والرقابية (Project Leadership & QA Audit)
- [ ] الإشراف على توزيع المهام ومتابعة تقدم الإخوة الخمسة.
- [ ] تدقيق ومراجعة فصول كتاب التحليل الأكاديمي المحالة من (حسين الحيدري، حمزه إبراهيم، عبدالحميد الريشاني) والتأكد من استيفاء شروط المناقشة الأكاديمية.
- [ ] فحص ملاءمة تصميمات الـ UI/UX الصادرة من (محمد المغربي) لقواعد التنفيذ البرمجي على الموبايل والويب.
- [ ] فحص كفاءة وأمان واجهات الـ RESTful API الصادرة من (محمد الرقاص) والتأكد من استقرار استجابات JSON ورموز الأخطاء (HTTP Status Codes).

### ب. المهام التقنية (تطوير تطبيق الموبايل - Flutter)
- [ ] بناء الهيكل المعماري الأساسي لتطبيق Flutter باتباع المعمارية النظيفة (**Clean Architecture**):
  - `core/` (الشبكة، الأخطاء، الثيمات، قواعد البيانات المحلية).
  - `features/auth/` (طبقات Data, Domain, Presentation).
  - `features/projects/` (طبقات Data, Domain, Presentation).
- [ ] تجهيز معمارية العمل دون اتصال (**Offline-First Architecture**) باستخدام `Hive` أو `SQLite/Isar` مع آلية التخزين المؤقت للبيانات (Cache-First Repository).
- [ ] بناء وتأمين طبقة الشبكة باستخدام `Dio` وإدارة التوكن (Bearer Token) و Interceptors لتجديد الجلسة والتعامل مع انقطاع الشبكة.
- [ ] بناء الشاشات الأولية:
  1. شاشة البداية المتحركة والشعار (**Splash Screen**).
  2. شاشة تسجيل الدخول والمصادقة المزدوجة (**Login Screen**).
  3. شاشة لوحة المتابعة الرئيسية للمشاريع (**Mobile Dashboard & Projects Screen**).

## 🔗 2. المدخلات والمخرجات المتبادلة

* **المدخلات التي ينتظرها عصام:**
  - من **محمد الرقاص**: مواصفات مسارات الـ API وتوثيق Postman لاختبار تسجيل الدخول وجلب بيانات المستخدم والمشاريع.
  - من **محمد المغربي**: أكواد ألوان الثيم (Light/Dark)، الأيقونات، وأحجام الخطوط، وسكتشات شاشات الموبايل المتوافقة مع Figma.
  - من **فريق التحليل (حسين، حمزه، عبدالحميد)**: مسودة الفصول (1، 2، 3) والمخططات الهندسية لمطابقتها مع وظائف التطبيق.
* **المخرجات التي يسلمها عصام:**
  - نسخة تجريبية أولية من تطبيق Flutter (APK / Windows Executable) قابلة للتشغيل وربط تسجيل الدخول مع السيرفر.
  - تقارير تدقيق وملاحظات تصحيحية لأعضاء الفريق.
